# 数据优先阶段计划：先补输入，再扩大排名

## 当前判断

项目当前的主要瓶颈已经从“有没有下载文档”转为“文档中的指标能否形成可审计观测”。最新基线：

- 全市场文档索引809份，文件存在且Hash校验809/809通过；
- 614家公司中612家有目标年度年报，612家有年报内嵌或独立ESG披露覆盖，只有2家目标年度年报仍缺失；
- 37项定量任务共22,718组，已形成候选8,125组，缺口14,593组，任务覆盖率约35.76%；
- 关键指标缺口4,566组；清洁能源、SO2、替代水三个指标低于最低人口20；
- 因此下一阶段重点不是继续优化页面或新增专利实验，而是把已下载文档转化为更多可靠指标观测。

## 缺失必须先分类

“缺失”不能直接等于“继续下载”。每个缺口先归入以下四类：

1. **文档缺失**：公司没有目标年度报告或下载失败；
2. **文档有、证据未发现**：PDF存在，但抽取规则没有命中；
3. **证据有、口径不兼容**：单位、分母、报告期或主体无法与指标定义对齐；
4. **真实未披露**：文档已充分检查仍没有目标指标。

只有第一类进入下载队列，第二类进入规则/文本抽取队列，第三类进入口径判断队列，第四类保留缺失并进入敏感性分析。

### D3：研究排名刷新

## 阶段验收

数据优先阶段完成的标准不是“所有格子都有值”，而是：

- 每个缺口都有可解释原因和下一动作；
- 文档存在但没有候选的任务已完成规则漏召回诊断；
- 高影响队列持续缩小且排名敏感性改善；
- 真实未披露不被伪造为零值或自动确认；
- 研究排名、证据链和缺失说明可以同步刷新。
