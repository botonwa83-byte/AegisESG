# 数据优先阶段计划：先补输入，再扩大排名

## 当前判断

项目当前的主要瓶颈已经从“有没有下载文档”转为“文档中的指标能否形成可审计观测”。最新基线：

- 全市场文档索引809份，文件存在且Hash校验809/809通过；
- 614家公司中612家有目标年度年报，612家有年报内嵌或独立ESG披露覆盖，只有2家目标年度年报仍缺失；
- 37项定量任务共22,718组，已形成候选8,125组，缺口14,593组，任务覆盖率约35.76%；
- 关键指标缺口4,566组；清洁能源、SO2、替代水三个指标低于最低人口20；
- 因此下一阶段重点不是继续优化页面或新增专利实验，而是把已下载文档转化为更多可靠指标观测。

## 缺失必须先分类

“缺失”不能直接等于“继续下载”。每个缺口先归入以下四类：

1. **文档缺失**：公司没有目标年度报告或下载失败；
2. **文档有、证据未发现**：PDF存在，但抽取规则没有命中；
3. **证据有、口径不兼容**：单位、分母、报告期或主体无法与指标定义对齐；
4. **真实未披露**：文档已充分检查仍没有目标指标。

只有第一类进入下载队列，第二类进入规则/文本抽取队列，第三类进入口径判断队列，第四类保留缺失并进入敏感性分析。

## 新的主次顺序

### D0：数据缺口基线（立即执行）

- 以`all_markets_document_index.csv`作为唯一当前文档索引；
- 为每个公司×指标任务生成`missing_reason`和`next_action`；
- 将缺口按“排名影响×指标权重×可抽取性”排序；
- 统计每轮新增候选、误召回、重复候选和真实未披露数量。

已生成`output/audit/data_gap_baseline_v1_2025.csv`和摘要JSON：22,718组任务中，8,125组已有候选，
14,519组为“文档存在但尚未发现候选、需要抽取/披露诊断”，74组属于公司年报缺失导致的下载队列。
系统暂不把14,519组直接判为真实未披露，避免把规则漏召回误当成数据不存在。

### D1：高影响指标补证

- 优先处理跨前200边界和高影响任务，而不是平均扫描全部14,593个缺口；
- 先处理GHG排放强度、减排率、能源强度、ROE/收入增长等高权重或高人口指标；
- 对同一版式建立规则正例和污染反例，新增规则必须通过全量零丢失回归；
- 每轮只接受带公司、报告期、文件、页码、原文和Hash的候选。

已执行首批影响排序：14,519个缺口中，4,514个跨前200边界，1,826个达到高影响阈值，4,546个属于关键指标缺口。
已切出25家公司、每家公司10项任务，共250项首批补证/抽取任务，产物为`data_gap_high_impact_companies_v1_2025.csv`
和`data_gap_high_impact_tasks_v1_2025.csv`；该批次`scoring_authorized=false`，只用于补证和诊断，不直接写入正式评分。

250项首批任务已完成文本诊断（`data_gap_high_impact_diagnostics_v1_2025.csv`）：92项相关字段不完整，65项未命中文档披露，
49项存在相关披露但没有兼容强度口径，36项涉及模糊强度、外币分母、非营收分母或范围冲突。下一轮优先处理可闭合的
公式字段和口径冲突，不把文本命中直接升级为确认观测。

D1.2已将250项任务转为动作队列：141项检查原始PDF表格，38项人工核验单位/分母/边界，71项保留缺失并继续扫描。
产物为`data_gap_diagnostic_action_queue_v1_2025.csv`及摘要；全部保持`scoring_authorized=false`。

D1.3已生成可直接浏览的`data_gap_diagnostic_review_packet_v1_2025.html`，按批次展示企业、中文指标、影响分、诊断类别、
页码、原文片段和下一动作，作为后续人工/规则复核的统一任务包。

由于首批诊断没有形成足够可直接授权的公式闭合项，D2薄样本专项已并行切出75项任务：清洁能源强度、SO2强度、
替代水率各25项，产物为`thin_population_gap_batch_v1_2025.csv`；该批次用于判断真实未披露与规则漏召回，仍不授权评分。

D2.1诊断结果：替代水率25项全部为相关字段不完整；清洁能源强度24项相关字段不完整、1项出现可能的营收闭合线索；
SO2强度17项无匹配披露、7项相关披露但无兼容强度口径、1项模糊强度。当前没有足够依据扩展规则或解除薄样本门禁，
唯一清洁能源线索进入人工口径复核队列。

D2.2已生成`thin_population_review_packet_v1_2025.html`，按指标和企业展示页码、原文片段、诊断类别及复核动作，
并明确不得降低最低人口、混用SOx/SO2、强行换算分母或把缺失记零。

### D2：低覆盖指标专项

- 清洁能源强度、SO2强度、替代水率分别建立口径诊断；
- 有同口径披露才扩展规则；没有足够人口则保留薄样本警告；
- 不通过降低门槛或把其他指标强行换算来制造覆盖率。

### D3：研究排名刷新

- 每批新增观测后自动重建研究预排名、敏感性和高影响队列；
- 判断排名稳定性是否改善，而不是只追求候选数量增长；
- 完整数据链企业优先进入客户 Demo，其他企业继续显示缺失原因。

## 暂缓但保留的工作

- 正式双审、仲裁和632家公司发布冻结：保留在P2，不阻塞D0～D3；
- 页面美化：只做影响理解的必要修复，不再作为当前主线；
- 专利实验和增量性能：保留研发证据，但暂停新增实验，直到数据覆盖形成稳定基线。

## 阶段验收

数据优先阶段完成的标准不是“所有格子都有值”，而是：

- 每个缺口都有可解释原因和下一动作；
- 文档存在但没有候选的任务已完成规则漏召回诊断；
- 高影响队列持续缩小且排名敏感性改善；
- 真实未披露不被伪造为零值或自动确认；
- 研究排名、证据链和缺失说明可以同步刷新。
