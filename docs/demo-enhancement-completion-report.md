```
Demo层次结构
├── Layer 1: 对比总览 (tier-comparison)
│   └── 基础 vs 高级排名对比
│       - 静态展示
│       - 价值主张
│
├── Layer 2: 数据分析 (data-visualization)
│   └── 聚合统计和质量分析

│       - 指标统计
```

1. **发现价值** → tier-comparison（为什么要付费？）
