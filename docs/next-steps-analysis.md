### 优先级3: 扩展数据源采集 ⭐ **中期任务**

**目标**: 从权威来源获取环境排放数据

**潜在数据源**:
1. **生态环境部 - 全国排污许可证管理信息平台**

**实施挑战**:

- 数据格式不统一，需要清洗
- 匹配公司主体（统一社会信用代码）

**预期时间**: 1-2周（每个数据源）

### 优先级4: 时间序列预测实战 🔄 **需要更多历史数据**

#### 当前限制
- 仅有1年历史数据（2024 vs 2025）
- 时间序列预测通常需要3-5年数据才有统计显著性

#### 可行替代方案
使用简单的**YOY增长预测**:
```python
# 基于2024→2025增长率预测2026
predicted_2026 = value_2025 * (1 + growth_rate_2024_to_2025)
confidence = 0.5  # 低置信度，仅1年样本
```

**应用场景**: 
- 仅用于PROFESSIONAL级别（最高级会员）
- 明确标注为"趋势推测"而非"预测"
- 不用于正式排名，仅供研究参考

**预期时间**: 2天

## 六、风险与应对

### 风险1: 外部数据源采集失败
- **概率**: 中
- **影响**: 覆盖率无法进一步提升
- **应对**: 保持当前85%覆盖率，重点提升数据质量和透明度

### 风险2: 客户质疑填充数据合理性
- **概率**: 中高
- **影响**: 高级排名产品推广受阻
- **应对**: 
  - 生成详细审计报告，标注所有填充项
  - 提供行业基准对比验证填充合理性
  - 明确区分"研究排名"vs"正式排名"

### 风险3: 历史数据始终无法获取
- **概率**: 中
- **影响**: 时间序列预测功能无法上线
- **应对**: 
  - 接受现状，预测功能标记为"未来功能"
  - 重点发展公式推导和数据源扩展
