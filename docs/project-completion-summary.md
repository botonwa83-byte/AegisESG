### 4.2 扩展模型设计

**ValueStatus枚举**:
```python
class ValueStatus(str, Enum):
    CONFIRMED = "confirmed"      # 原始披露
    PENDING = "pending"          # 待审核
    MISSING = "missing"          # 缺失
    NOT_APPLICABLE = "not_applicable"  # 不适用
    DERIVED = "derived"          # 公式推导
    PREDICTED = "predicted"      # 时间序列预测
    IMPUTED = "imputed"          # 行业填充
```

**Observation扩展字段**:
- `source_type`: 数据来源类型
- `note`: 备注（如推导公式）
- `confidence`: 置信度评分
- `collected_at`: 采集时间
