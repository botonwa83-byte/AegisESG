# aegisESP 真实数据 Demo 领导演示脚本

建议时长：5—10分钟。演示对象看到的是公开数据自动研究预排名，不是正式发布榜单。

## 开场（30秒）

> 今天演示的是系统的自动化研究能力：系统从公开年报和ESG报告中抽取真实数据，形成可追溯的
> 预排名，并同时展示数据缺失、敏感性和正式审核门禁。页面中的结果不是官方榜单，也没有绕过人工审核。

## 操作步骤

1. 打开`output/demo/real_data_demo_2025/ranking.html`。
2. 指出页面标题中的“自动预排名·非正式”，说明当前覆盖612家公司。
3. 查看前10—20名，展示证券代码、公司、指标原值、指标分值和综合分。
4. 选长江电力（`600900.SH`）或思源电气（`002028.SZ`），说明有些指标显示为“-”是公开资料未形成
   可确认口径，不是系统偷偷填0。
5. 打开`ranking_sensitivity.json`，展示三种缺失策略的名次跨度、Top-N重合率和相关性；说明系统
   会把不稳定性暴露给领导，而不是只给一个看似精确的名次。
6. 打开`ranking_metadata.json`，展示`auto_prerank_v1`、缺失策略版本、输入Hash和
   `official_release=false`。
7. 打开`external_readiness_2025.json`，展示六道门禁、审核签名和专利权属仍未闭合。
8. 最后说明正式版本的路径：冻结632家公司主体、真实审核、双签授权后，才允许运行固定正式算法。

## 现场问答口径

| 领导可能问 | 建议回答 |
|---|---|
| 这是正式排名吗？ | 不是，这是公开数据研究预排名；正式排名有独立固定算法和人工审核门禁。 |
| 为什么有些指标为空？ | 只有满足主体、年份、单位和分母约束才纳入；无法确认就保留缺口，避免制造假精确。 |
| 能否自动完成？ | 预排名可以自动完成；正式排名仍需主体、冲突、高风险定性和发布授权审核。 |
| 数据能追溯吗？ | 每条观测带来源、页码、证据和Hash；演示包也有文件Hash清单。 |
| 什么时候能正式发布？ | 需要完整632主体表、真实审核签名、方法论裁决、专利权属确认和正式双签。 |

## 演示禁区

- 不删除“自动预排名·非正式”水印；
- 不把排名序号称为客户最终名次；
- 不承诺与报告发布机构官方分数一致；
- 不现场修改数据或为了展示效果调整算法；
- 不展示空白签名模板为“已审核证明”。

## 页面打不开时的备用方式

在项目根目录或`scripts`目录执行（不需要`sudo`）：

```bash
python3 -m http.server 4173 --directory output/demo/real_data_demo_2025
```

然后访问`http://127.0.0.1:4173/ranking.html`。演示结束后停止该本地服务即可。
