# 真实数据 Demo 评估与演示方案

## 可行性结论

可行。当前已有612家公司、34,304条研究观测、前200 HTML/CSV/JSON排名、敏感性分析、算法元数据和
外部输入审计，足以展示一条真实、可追溯的自动预排名流水线。

演示包位于`output/demo/real_data_demo_2025/`。它的定位是向领导展示产品能力和研究闭环，不是正式
商业榜单交付。页面保留“自动预排名·非正式”水印，元数据明确`official_release=false`。
具体讲解顺序和现场问答见[领导演示脚本](real-data-demo-script.md)。
如果要演示系统全貌（Dashboard、证据、审核和冻结），请使用[系统全貌 Demo](real-system-demo.md)。

## 演示价值

- 看到真实公司和真实披露数据，而不是样例数据；
- 看到指标数值、指标分值、综合分和前200输出；
- 看到缺失策略敏感性和可信等级，理解系统不会制造虚假精确度；
- 看到输入Hash、方法论版本、算法版本和正式发布门禁；
- 看到自动排名与正式审核排名的隔离设计。

## 不应承诺

当前研究排名存在612/632主体范围、薄样本、真实审核签名、定性基准集和专利权属待确认等限制。
演示时应称“公开资料自动研究预排名 Demo”，不应称“正式632家公司榜单”“官方复刻”或“已完成发布”。
