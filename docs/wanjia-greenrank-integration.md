经公开检索确认，公司的官方公开站点为：[greenrank.com.cn](https://www.greenrank.com.cn/)，品牌名为“万绿信评”。

## 正式嵌入方式

真正嵌入官方站点必须由官网管理员授权并选择一种部署方式：

1. **官方子路径**：`greenrank.com.cn/esg-rating/` 反向代理到本系统生产服务；
2. **官方子域名**：`esg.greenrank.com.cn` 指向独立部署的系统；
3. **官方页面链接/按钮**：官网导航进入独立 Demo 或正式评价系统；
4. **iframe**：仅适合内部试用，正式交付前需处理登录、CSP、Cookie、移动端和安全策略。

当前 GitHub Pages 版本只是公开静态演示，不具备正式数据写入、人工签名和权限控制能力。未获得授权前，
不得复制官网源码、Logo或宣称该页面属于官方生产系统；正式集成需要域名、部署权限、品牌素材和法务/信息安全确认。
