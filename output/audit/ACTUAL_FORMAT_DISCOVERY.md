# 🔍 关键发现 - 实际披露格式分析

## 发现的实际格式

### 格式1：表格行格式（最常见）
```
温室气体排放强度 吨二氧化碳当量/百万元 38.02 44.11
能源消耗强度 tce/百万元 4.03 9.94 10.40
```

**特点**：
- 指标名称 + 单位 + 多个年份数值
- 数值之间用空格分隔
- 单位可能是 /百万元 而非 /万元

### 格式2：简洁展示
```
温室气体排放强度
44.11吨/百万元营收
```

### 格式3：表头+数据
```
总能源消耗强度
MWh/百万元 32.79 80.88 84.62
```

## 🔴 我们的规则问题

当前规则要求：
- 指标名称和数值在同一行
- 单位必须是 /万元
- 格式必须严格匹配

实际情况：
- 数值可能在下一行
- 单位是 /百万元 （需要÷100换算）
- 格式多样化

## 💡 解决方案

需要：
1. 支持多行匹配（标签在上行，数值在下行）
2. 支持 /百万元 单位
3. 从多个数值中提取正确年份
4. 更灵活的格式匹配
