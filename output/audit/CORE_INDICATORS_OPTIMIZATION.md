## 🔧 优化细节

### 1. DirectRule多模式覆盖（新增12条）

为每个核心指标添加3种匹配模式：

#### 模式1: 基础强度模式（原有）
```python
r"(?:温室气体|GHG|碳)(?:排放)?强度\s+数值"
```

#### 模式2: 每百万营收模式（新增）
```python
r"(?:每百万|单位)(?:元)?(?:营收|营业收入)(?:的)?(?:温室气体|碳)(?:排放)?(?:量|强度)?\s+数值"
```
**覆盖场景**: "每百万元营收温室气体排放量"、"单位营收碳排放"

#### 模式3: 万元/百万元产值模式（新增）
```python
r"(?:万元|百万元)(?:产值|营收|收入)(?:温室气体|碳)(?:排放)?\s+数值"
```
**覆盖场景**: "万元产值碳排放"、"百万元营收GHG"

## 📊 优化策略

### 三层覆盖体系

#### 第1层: DirectRule（表格行尾数值）
- 匹配模式: `指标名称 + 单位 + 多个数值 + 行尾最后数值`
- 优势: 精确提取表格中2025年数据
- 覆盖: 标准ESG报告表格

#### 第2层: _rule（标签+单位+数值）
- 匹配模式: `指标标签 + 数值 + 单位`
- 优势: 覆盖文本描述场景
- 覆盖: 段落文本、亮点卡

#### 第3层: indicator_keywords（简单表格）
- 匹配模式: 关键词在表格标签中
- 优势: 覆盖简化表格
- 覆盖: 无明确单位的KPI表

### 多变体穷举策略

针对企业报告中的多种表述方式：

| 标准表述 | 企业变体1 | 企业变体2 | 企业变体3 |
|---------|----------|----------|----------|
| 温室气体排放强度 | 碳排放强度 | 每百万营收温室气体 | 万元碳排放 |
| 综合能源消耗强度 | 能耗强度 | 单位营收能耗 | 万元能耗 |
| 二氧化硫排放强度 | SO2强度 | 每百万营收SO2 | 万元二氧化硫 |

**每个变体都有对应的DirectRule或关键词**

## 💡 技术亮点

### 1. 多模式穷举法
不依赖单一正则，而是为每种常见表述建立独立规则：
- 基础模式：温室气体排放强度
- 营收模式：每百万营收温室气体
- 产值模式：万元产值碳排放

### 2. 关键词爆炸策略
从企业实际报告中提取高频变体：
- 学术表述：温室气体排放强度
- 简化表述：碳强度、碳密度
- 单位表述：万元碳排放
- 英文表述：GHG intensity

### 3. 年份智能选择
使用行尾匹配确保提取2025年数据：
```python
r"(?:[\d,]+(?:\.\d+)?\s+)*" +  # 跳过2024年数据
NUMBER + r"\s*$"  # 匹配行尾2025年数据
```

### 4. 三层覆盖保障
- DirectRule: 表格精确提取
- _rule: 文本通用提取
- indicator_keywords: 简单表格兜底
