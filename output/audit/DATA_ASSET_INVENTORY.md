### 清理操作
```bash
# 查找空目录
find data/raw -type d -empty

# 查找重复文件（基于大小）
find data/raw -name "*.pdf" -type f -exec ls -lh {} \; | awk '{print $5, $9}' | sort | uniq -D -w 10

# 清理临时文件
find data/raw -name "*.tmp" -o -name "*.part" -delete
```

### 备份操作

# 验证备份完整性
tar -tzf backup_ci_collection_*.tar.gz | wc -l
