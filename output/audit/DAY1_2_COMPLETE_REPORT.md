## 📊 优化对比

### 规则灵活性提升

**优化前（过严）**：
```python
r"千克标准煤/万元营收"
# 只匹配：千克标准煤/万元营收
# 漏掉：kg标煤/万元营业收入 ❌
# 漏掉：吨标煤/百万元 ❌
```

**优化后（灵活）**：
```python
r"(?:千克|kg|吨)(?:标准煤|标煤)?[/／](?:万|百万)?元(?:营收|营业收入|收入)?"
# 匹配：千克标准煤/万元营收 ✅
# 匹配：kg标煤/万元营业收入 ✅
# 匹配：吨标煤/百万元 ✅
# 匹配：千克/万元收入 ✅
```
