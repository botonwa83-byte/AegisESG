## 🔍 表格识别机制

### 检测逻辑
```
1. 扫描每行文本
2. 查找3+连续空格（列分隔符）
3. 分割为标签和数值列
4. 验证列数 ≥ 2
```

### 示例表格格式
```
支持格式1: 标准对齐
温室气体排放强度     1.23    1.15    吨CO2e/万元
能源消耗强度         0.45    0.42    吨标煤/万元

支持格式2: 多空格分隔
GHG排放强度   1.23   1.15
水资源强度    2.34   2.10

支持格式3: 宽表格
指标            2024年   2025年   单位
温室气体强度    1.23     1.15     吨/万元
```

## ⚠️ 当前限制

### 不支持的格式
1. ❌ 复杂HTML表格（带合并单元格）
2. ❌ 斜线表头
3. ❌ 多级表头
4. ❌ 单位在表格外
5. ❌ 不对齐的表格

### 识别误差
- 可能误判普通文本为表格
- 可能提取到非当前年份数值
- 需要置信度和审核机制补充
