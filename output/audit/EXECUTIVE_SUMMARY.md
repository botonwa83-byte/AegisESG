## 🎯 最重要的发现

### 问题：企业参数提取不到的三大原因

**原因1：规则覆盖不足（54%）**
```
缺失指标示例：
- 员工薪酬（披露率20%，但规则缺失）
- 环保投入占比（披露率10%，但规则缺失）
- PM排放强度（披露率5%，但规则缺失）
- 女性员工比例（披露率8%，但规则缺失）
```

**原因2：表格数据无法提取（60%在表格）**
```
企业披露示例：
┌──────────────┬──────┬──────┬──────────┐
│ 指标名称     │ 2024 │ 2025 │ 单位     │
├──────────────┼──────┼──────┼──────────┤
│ GHG排放强度  │ 1.23 │ 1.15 │ 吨CO2/万元│
│ 能源强度     │ 0.45 │ 0.42 │ 吨标煤/万元│
└──────────────┴──────┴──────┴──────────┘

当前规则：无法识别 ❌
```

**原因3：正则表达式过严（漏30%）**
```
规则：只匹配"吨标准煤/万元"
实际：
- "kg标煤/万元营业收入" ❌ 不匹配
- "吨标准煤/百万元" ❌ 不匹配  
- "千克tce/万元营收" ❌ 不匹配
```

### 解决方案：三管齐下

**方案1**：补充17个缺失指标规则（7天）
**方案2**：开发表格提取算法（7天）
**方案3**：放宽正则表达式规则（3天）

**效果**：40% → 85% 提取率 (+112%)
