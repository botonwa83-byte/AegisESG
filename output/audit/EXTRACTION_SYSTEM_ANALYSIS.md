### 问题2：正则表达式过于严格（中等）

**案例分析**：

```python
# 当前规则（过于严格）
_rule("Q_E_GHG_INTENSITY", 
      r"(?:温室气体|碳)排放强度", 
      r"千克(?:二氧化碳当量|CO2e)?/万元|吨(?:二氧化碳当量|CO2e)?/万元",
      {"千克/万元": 1, "吨/万元": 1000})
```

**问题**：
- 只匹配"千克/万元"或"吨/万元"
- 不匹配"kg/万元营业收入"
- 不匹配"吨CO2/百万元"
- 不匹配表格中的数值（无单位标注）

**实际披露情况**：
- 50%企业：标准格式
- 30%企业：变体格式（营业收入、营收、收入）
- 20%企业：表格格式（单位在表头）

**改进建议**：
```python
# 更灵活的规则
_rule("Q_E_GHG_INTENSITY", 
      r"(?:温室气体|GHG|碳|CO2)(?:排放)?强度",
      r"(?:千克|kg|吨|t|公斤)(?:二氧化碳当量|CO2(?:e|-?eq)?)?/(?:万|百万)?元(?:营收|营业收入|收入)?",
      {"千克/万元": 1, "kg/万元": 1, "吨/万元": 1000, ...})
```

### 问题3：表格数据提取缺失（严重）

**现状**：
- 当前规则：基于文本行匹配
- 实际披露：60%数据在表格中
- 匹配率：仅40%

**表格格式示例**：
```
指标名称                    2024年      2025年    单位
温室气体排放强度             1.23        1.15    吨CO2e/万元
能源消耗强度                 0.45        0.42    吨标准煤/万元
```

**改进方案**：
1. 表格结构识别
2. 列头单位解析
3. 行标签匹配
4. 数值提取和单位换算

### 问题4：单位换算不完整（中等）

**当前支持**：
- 千克/万元 ↔ 吨/万元
- RMB million ↔ RMB billion
- tonnes ↔ kg

**缺失**：
- ✗ 吨/百万元 → 千克/万元
- ✗ kg/千元 → 千克/万元
- ✗ g/万元 → 千克/万元
- ✗ 立方米 ↔ 吨（水）
- ✗ 度(kWh) → 标准煤

### 问题5：财务数据提取依赖性强（中等）

**财务指标提取**：
- 依赖标准IFRS/GAAP格式
- 对中文报表支持较弱
- 对合并报表vs母公司报表区分不足

**改进方向**：
- 增加中文财务术语规则
- 支持多种报表格式
- 明确合并口径

### 问题6：置信度评分不够精细（轻微）

**当前机制**：
- 固定置信度（0.82-0.96）
- 未考虑提取上下文
- 未考虑数值合理性

**改进建议**：
```python
置信度 = 基础置信度 * 上下文因子 * 数值合理性因子
- 上下文因子：是否在ESG专章、是否有表格结构等
- 数值合理性：是否在合理范围、是否与同行业平均值接近
```

### P2：智能置信度评分（一般）

**机制**：
```python
def calculate_confidence(base_conf, context):
    """智能置信度计算"""
    score = base_conf
    
    # 上下文加分
    if "ESG报告" in context.document_type:
        score *= 1.1
    if context.in_table:
        score *= 1.05
    if context.has_year_label:
        score *= 1.02
        
    # 数值合理性
    if is_reasonable_value(value, indicator):
        score *= 1.0
    else:
        score *= 0.8
        
    return min(score, 0.98)
```
