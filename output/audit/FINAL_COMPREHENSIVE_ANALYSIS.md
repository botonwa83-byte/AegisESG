## 三、根本问题诊断

### 问题1：单位体系不统一 🔴

**标准vs实际**：

| 指标 | DLT标准单位 | 企业常用单位 | 换算关系 |
|------|------------|-------------|---------|
| GHG强度 | 吨CO2e/万元 | 吨CO2e/百万元 | ÷100 |
| 能源强度 | 吨标煤/万元 | tce/百万元 | ÷100 |
| 水资源 | 立方米/万元 | 吨/百万元 | ÷100 |
| NOx | 千克/万元 | 克/万元 | ×1000 |
| SO2 | 千克/万元 | 克/万元 | ×1000 |

**当前系统问题**：
- DirectRule的factor固定为1.0
- 没有根据单位动态换算
- 提取的数值可能错误

**解决方案**：
需要在extraction.py中增强单位识别和换算逻辑

### 问题2：表格数据识别率低 🔴

**实际披露格式**（通过分析发现）：
```
格式1: 表格横排（最常见60%）
指标名 单位 2023 2024 2025
温室气体排放强度 吨CO2e/百万元 40.23 38.02 44.11

格式2: 分行显示（30%）
温室气体排放强度
44.11吨/百万元营收

格式3: GRI索引（10%）
103-4 能源强度
（数据在其他页）
```

**当前问题**：
- 只能识别部分格式1
- 格式2识别率低
- 格式3几乎无法识别
- 年份选择有误（已修复）

### 问题3：关键词覆盖不全 🟡

**示例**：

def normalize_unit_value(value, unit_text):
    """根据单位文本换算数值"""
    # 百万元 → 万元
    if "百万元" in unit_text:
        return value * 0.01  # ÷100
    # 克 → 千克
    elif "克/万元" in unit_text and "千克" not in unit_text:
        return value * 1000
    return value
