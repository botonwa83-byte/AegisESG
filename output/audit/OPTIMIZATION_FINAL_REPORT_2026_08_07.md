## 当前限制与挑战

### 1. 覆盖率瓶颈
**现状**: 核心指标平均覆盖率仅12%，远低于90%目标

**根本原因**:
- 大量企业**不披露**这些指标（尤其是SO2、NOx、固废）
- 能源企业ESG披露质量参差不齐
- 部分企业仅披露定性描述，无定量数据

### 2. 企业披露习惯分析

**已分析599家企业的文本**，发现：

#### 高覆盖率指标 (>40%)
- Q_S_PAY_PER_EMPLOYEE (4,076条，41.8%): 员工薪酬，年报必披露
- Q_S_RD_RATE (1,910条，19.6%): 研发费用占比，年报必披露
- Q_G_DEBT_ASSET_RATE (873条，89.5%): 资产负债率，年报必披露

#### 中覆盖率指标 (10-40%)
- Q_E_GHG_INTENSITY (20.6%): 大型能源企业披露
- Q_E_ENERGY_INTENSITY (15.2%): 能源消耗强度

#### 低覆盖率指标 (<10%)
- Q_E_SO2_INTENSITY (6.2%): 主要是火电、钢铁企业披露
- Q_E_NOX_INTENSITY (8.2%): 同上
- Q_E_SOLID_WASTE_INTENSITY (9.4%): 固废管理要求严格的企业
- Q_S_FEMALE_MANAGER_RATE (1.5%): 很少企业披露女性管理层比例

### 3. 数据质量问题
- 单位不统一：同一指标企业使用不同单位
- 口径差异：范围一+范围二 vs 仅范围一
- 年份混淆：表格中2024/2025年数据混排

## 达到90%覆盖率的路径分析

### 方案1: 扩展提取规则（当前方案）
**预期效果**: 最多提升到30-40%

**原因**: 
- 大部分低覆盖率指标企业根本不披露
- 继续优化规则收益递减

**剩余优化空间**:
- 员工相关指标: 通过提取员工总数、女性员工数，计算比率
- 财务比率: 部分可从年报财务数据计算
- 估计可新增300-500条记录

### 方案2: 数据插补和估算
**方法**:
1. **行业平均值填充**: 同行业平均值替代缺失值
2. **回归预测**: 基于相关指标预测缺失指标
3. **历史数据外推**: 从2024年数据推算2025年
4. **标杆对标**: 使用行业标杆值

**预期效果**: 可达到90%+覆盖率

**风险**: 
- 引入估算误差
- 评分准确性下降
- 需要明确标注估算来源

### 方案3: 混合策略（推荐）
**组合方案**:
1. **Tier 1**: 直接提取（当前12%）
2. **Tier 2**: 从已有数据计算（目标+10%）
3. **Tier 3**: 行业平均值填充（目标+30%）
4. **Tier 4**: 回归预测（目标+38%）

**总计**: 12% + 10% + 30% + 38% = 90%

**实施要求**:
- 建立数据分级体系
- 标注数据来源（extracted/calculated/filled/predicted）
- 调整不同来源数据的置信度权重

## 技术文档

### 单位转换规则
```python
# GHG强度: 吨CO2e/百万元 → 千克CO2e/万元
factor = 1000 (吨→千克) × 0.01 (百万元→万元) = 10

# NOx/SO2强度: 吨/百万元 → 克/万元  
factor = 1000000 (吨→克) × 0.01 (百万元→万元) = 10000

# 能源强度: 吨标煤/百万元 → 千克标煤/万元
factor = 1000 × 0.01 = 10
```

### 计算公式示例
```python
# 温室气体排放强度
intensity = (emission_tons * 1000) / (revenue_yuan / 10000)

# 研发费用占比
rd_rate = (rd_expense / revenue) * 100

# 女性员工比例
female_rate = (female_count / total_employee) * 100
```
