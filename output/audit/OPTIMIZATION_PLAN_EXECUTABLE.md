## 一、系统的真实缺陷

### 缺陷1：单位定义与实际披露严重不匹配 🔴

**方法论定义**：
```json
{
  "Q_E_GHG_INTENSITY": {
    "unit": "千克/万元",
    "formula": "范围一和范围二温室气体排放总量(千克CO2e)/营业收入(万元)"
  }
}
```

**实际企业披露**：
- 单位：吨/百万元（不是千克/万元）
- 差异：1000倍（吨vs千克）× 0.01（百万元vs万元）= 10倍

**问题**：
- ❌ extraction.py中的单位换算不完整
- ❌ DirectRule的factor固定为1.0，无法动态调整
- ❌ 导致提取的数值可能错误10-100倍

### 缺陷2：规则与披露格式脱节 🔴

**_rule函数的假设**：
```python
# 假设格式：指标名 + 数值 + 单位
"温室气体排放强度 44.11 吨/万元"
```

**实际披露格式**：
```
格式1（60%）: 温室气体排放强度 吨/百万元 38.02 44.11
格式2（30%）: 温室气体排放强度\n44.11吨/百万元营收
格式3（10%）: GRI索引（数据在其他页）
```

**问题**：
- ❌ _rule生成的正则无法匹配格式1（单位在数值前）
- ❌ 无法处理多年份数据（提取错误年份）
- ❌ 无法处理换行分隔

### 缺陷3：关键指标权重高但提取率极低 🔴

**方法论定义的关键指标**：
```json
{
  "Q_E_SO2_INTENSITY": { "weight": 2.48, "key_indicator": true },
  "Q_E_NOX_INTENSITY": { "weight": 2.48, "key_indicator": true },
  "Q_E_SOLID_WASTE_INTENSITY": { "weight": 3.82, "key_indicator": true }
}
```

**实际提取率**：
- SO2: 3.8%（585/612缺失）
- NOx: 6.0%（572/612缺失）
- 固废: 8.2%（553/612缺失）

**问题**：
- ❌ 高权重指标提取率极低，影响评分准确性
- ❌ 没有针对关键指标的特殊优化

### 缺陷4：缺少单位标准化层 🔴

**当前流程**：
```
文本 → 正则匹配 → 提取数值 → 直接保存
```

**缺少的环节**：
```
提取数值 → [单位识别] → [单位换算] → [标准化] → 保存
```

**问题**：
- ❌ 没有统一的单位标准化模块
- ❌ 每个规则独立处理单位，不一致
- ❌ 无法验证数值的合理性

### 缺陷5：表格提取未真正实现 🔴

**代码中的表格提取**：
```python
def extract_from_simple_tables():
    # 实现了，但效果很差
    # 只新增52条记录（+0.6%）
```

**问题**：
- ❌ 表格检测算法识别率低（<10%）
- ❌ 关键词匹配不到实际表格标签
- ❌ 单位提取逻辑有问题
- ❌ 多年份列选择错误

### 缺陷6：缺少数据验证和清洗 🔴

**当前流程**：
```
提取 → 直接输出到CSV
```

**缺少的验证**：
- ❌ 数值合理性检查（是否在正常范围）
- ❌ 单位一致性验证
- ❌ 异常值过滤
- ❌ 重复值检测

### 缺陷7：定性指标完全未实现 ⚠️

**方法论定义**：
- 43个定性指标（20%权重）
- 包括：气候风险、生物多样性、绿色转型等

**当前状态**：
- ❌ extraction.py只处理定量指标
- ❌ 定性指标提取率：0%
- ❌ 影响20%的总分
