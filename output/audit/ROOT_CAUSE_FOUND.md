# 🔴 根本问题发现！

## 致命缺陷

### _rule 函数的模式
```python
# 当前模式：标签 + [35字符] + 数值 + 单位
r"(?:温室气体排放强度)[^\d%]{0,35}([+-]?[\d,]+(?:\.\d+)?)\s*(吨/万元)"
```

### 实际披露格式
```
温室气体排放强度 吨二氧化碳当量/百万元 38.02 44.11
              ↑              ↑
            单位           数值
```

**顺序相反！实际是：标签 + 单位 + 数值**

## 这就是为什么规则不起作用！

所有使用 `_rule` 函数的规则都无法匹配表格格式的数据。

## 解决方案

需要：
1. 使用 `DirectRule` 替代 `_rule`（可以自定义模式）
2. 或者修改 `_rule` 函数支持两种模式
3. 或者添加专门的表格提取规则
