### 实际披露格式（基于样本分析）

**格式1：表格形式（最常见）**
```
二氧化硫排放强度 克/万元 2.3 1.8 1.5
SO2排放强度 g/万元 2.5 2.1
```

**格式2：文本形式**

二氧化硫排放强度为1.5克/万元营业收入

**格式3：单位变体**
```
二氧化硫 千克/万元 0.0015
SO2 吨/百万元 0.000015
```

## 优化方案

### 1. 增强DirectRule

需要添加更灵活的SO2和NOx规则：

```python
# SO2 - 目标单位：克/万元
DirectRule(
    "Q_E_SO2_INTENSITY",
    re.compile(
        r"(?:二氧化硫|SO2|硫化物)(?:排放)?强度\s+" +
        r"(?:[^\n]*?)" +  # 允许单位和其他内容
        r"(?:[\d,]+(?:\.\d+)?\s+)*" +  # 跳过前面年份
        NUMBER + r"\s*$",  # 行尾数值
        re.I | re.MULTILINE
    ),
    1.0,
    0.82,
),

# NOx - 目标单位：克/万元
DirectRule(
    "Q_E_NOX_INTENSITY",
    re.compile(
        r"(?:氮氧化物|NOx|NOₓ)(?:排放)?强度\s+" +
        r"(?:[^\n]*?)" +
        r"(?:[\d,]+(?:\.\d+)?\s+)*" +
        NUMBER + r"\s*$",
        re.I | re.MULTILINE
    ),
    1.0,
    0.82,
),
```
