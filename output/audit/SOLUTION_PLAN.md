# 🎯 根本问题与解决方案

基于对DLT 2971-2025标准和实际数据的分析：

## 核心问题

### 1. 单位不匹配（最关键）
**标准要求**：吨/万元  
**企业披露**：吨/百万元  
**差异**：100倍！

**影响**：
- 即使提取到数据，数值也可能错误
- 需要正确的单位换算

### 2. 表格格式识别率低
**实际格式**：
```
指标名 单位 2023 2024 2025
温室气体排放强度 吨/百万元 40.23 38.02 44.11
```

**问题**：
- 我们的规则提取了第一个数值（38.02）而非最后一个（44.11）
- 已修复但需验证效果

### 3. 提取规则不够灵活
**原因**：
- 披露格式多样化
- 关键词变体多
- 单位标注不统一

## 立即行动

### 优先级P0：完善单位换算

```python
# 单位换算表

```
