## 🔧 核心优化策略

### 1. 多模式DirectRule（新增12条）

为每个核心指标添加3种匹配模式：

#### 模式A: 基础强度（原有）
```
温室气体排放强度 → 数值
```

#### 模式B: 每百万营收（新增）
```
每百万元营收温室气体排放量 → 数值
单位营收碳排放 → 数值
```

#### 模式C: 万元产值（新增）
```
万元产值碳排放 → 数值
百万元营收GHG → 数值
```

### 2. 关键词爆炸式扩展（+36个）

每个核心指标新增6个关键词变体：

**GHG示例**（7个→13个）：
```
新增：温室气体强度, 碳密度, 每百万营收温室气体, 
     单位营收碳排放, 万元碳排放, 碳排放强度
```

**能源示例**（6个→12个）：
```
新增：能源密度, 每百万营收能耗, 单位营收能耗,
     万元能耗, 综合能源消耗强度, 能源消费强度
```

### 3. 三层覆盖体系

```
第1层：DirectRule（表格行尾）
       ↓ 未匹配
第2层：_rule（文本标签+单位）
       ↓ 未匹配
第3层：indicator_keywords（简单表格）
```

**确保零遗漏！**
